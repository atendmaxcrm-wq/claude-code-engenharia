# Exemplo: case de site / produto

Prova de que o motor nao e so futebol: titulo, mockup (print do site num celular, rolando) e barras (notas), com assinatura.
Coloque em `assets/`: `musica.mp3` e `site.png` (print de celular: Playwright com viewport 390x844, deviceScaleFactor 2, pagina inteira ou recorte alto).
As notas do exemplo sao ILUSTRATIVAS (a legenda diz isso); num video real use os numeros medidos (PageSpeed, etc).
